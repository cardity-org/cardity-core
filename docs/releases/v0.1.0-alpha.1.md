# Cardity Core v0.1.0-alpha.1

This is the first public alpha baseline for Cardity as a generic protocol
contract layer for AI-generated systems.

## Included

- `.car` protocol compiler.
- Protocol JSON, ABI, and CARC artifact generation.
- Agent OS manifest generation with `cardity.agent_manifest.v1`.
- Hosted HTTPS API and MCP-over-HTTP endpoint.
- Local CLI and stdio MCP adapters.
- Generic agent-action contract v1.
- Projection contract v1.1 for replay-safe read models.
- PMTSoul Agent OS validated downstream reference baseline.
- Merchant ERP reference example covering products, inventory, orders, store
  dashboard, store profile, rankings, and complaints.
- Machine-readable schema files in `schemas/`.
- Local conformance verification scripts.

## Out Of Scope

- Production workspace writes by Cardity itself.
- Private-key handling.
- Deploy/signing workflows as the default path.
- Agent-runtime policy decisions.
- GitHub Actions CI. Local conformance scripts are the current source of truth.

## Release Checks

```bash
npm run build
npm test
node scripts/verify_contract_schemas.js
```

## Compatibility

Downstream runtimes should consume:

- `system.api.routes`
- `system.database.tables`
- `system.database.read_models`
- `system.database.projections`
- `system.database.queries`
- `system.ui.actions`
- `system.modules`
- `system.external.navigation`
- `system.external.services`
- `permissions`
- `agent.tools`

Command actions without a concrete `permission` remain planned/dry-run only.
